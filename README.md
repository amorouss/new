# قهوه اقبال

فروشگاه آنلاین دانه قهوه [cafeiqbal.ir](https://cafeiqbal.ir) — برند اقبال.

## فرانت‌اند

```bash
cd frontend
npm install
npm run dev
```

ساخت نسخهٔ تولید:

```bash
cd frontend
npm run build
```

خروجی در `frontend/dist` است و روی `public_html` هاست منتشر می‌شود. API روی `https://api.cafeiqbal.ir` قرار دارد.
