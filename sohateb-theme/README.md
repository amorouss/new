# Soha Teb WordPress Theme

Custom storefront UI for **Soha Teb Beauty School** (`soha-teb.ir`).

## What this ships

- Brand-first homepage (hero + categories + featured products + spotlight)
- WooCommerce product cards for catalog / product intro
- RTL-friendly Persian typography (`Vazirmatn` + `Cormorant Garamond`)
- Demo placeholder products seeded on first theme activation
- Ready for real product content in the next step

## Install on hosting

1. Upload the `sohateb` theme folder to:
   `public_html/wp-content/themes/sohateb`
2. Activate theme **Soha Teb** in WP Admin → Appearance → Themes  
   (or set `template` / `stylesheet` options to `sohateb`)
3. Disable maintenance mode plugin
4. Ensure WooCommerce is active

## Notes

- Demo seed runs once (`sohateb_demo_seeded` option)
- Replace placeholder products with real catalog when ready
- Upload the official logo via Appearance → Customize → Site Identity
